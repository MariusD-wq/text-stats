# Text Stats

A command-line text analysis tool built with Python. Count words, characters, and lines in text provided as a command-line argument, and display the results in the terminal.

Built to practice Python fundamentals, string processing, command-line argument parsing with argparse, Python package structure, and automated testing with pytest.

## Features

- Count words separated by whitespace.
- Count characters, including spaces and newline characters.
- Count lines, with empty text returning zero.
- Display word, character, and line counts together.
- Run through the `text-stats` command after installation.
- Includes unit tests for individual counts, empty input, and combined statistics.
